# Internship Skill Tracker

A production-ready full-stack web application designed to help students and aspiring professionals manage their career journey by organizing technical skills, internships, certifications, and professional achievements in one centralized platform.

Built using **React, Spring Boot, and MySQL**, the application follows a RESTful architecture and provides secure user-specific data management, ensuring complete privacy and personalization for every user.

## Overview

Internship Skill Tracker provides a personalized dashboard where users can:

- Maintain and track technical skills
- Manage internship experiences
- Store and access certifications
- Monitor career progress
- Build a structured professional profile

The platform is designed to simplify career management and help users maintain a complete record of their professional growth.

---

## Features

### User Authentication
- Secure user registration and login
- Personalized user dashboard
- User-specific data isolation

### Skills Management
- Add, update, and delete technical skills
- Track skill proficiency levels
- Maintain a structured skill portfolio

### Certificate Management
- Upload certificates with file support
- Store certificate details
- View and download uploaded certificates

### Internship Tracking
- Add internship experiences
- Manage internship details
- Track internship status

- Dynamic career score calculation
- Overview of skills, internships, and certifications

- Centralized career information management

### User Interface
- Responsive design
- Modern dashboard layout
- Smooth navigation experience
